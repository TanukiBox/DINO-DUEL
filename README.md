# DINO DUEL／恐竜カードバトル

恐竜を集めて3体のチームを組み、3体対3体のターン制バトルで大会を勝ち進む、スマホ向けの無料ブラウザゲーム。
攻撃が当たる瞬間にタップすると威力アップ、相手の攻撃が当たる瞬間にタップするとダメージが減る。
作者：Tanuki Box

- 遊ぶ：https://tanukibox.github.io/DINO-DUEL/
- 課金要素なし。画像・音声ファイルは使わず、恐竜はオリジナルの SVG、効果音は Web Audio で作っている。

## 今の状態
**段階1（バトル1戦だけ遊べる）**。くわしくは `WBS.md`。
- タイトルで相手の強さ（ビギナー〜レジェンド）を選んで「バトル開始」。
- 自分のチームはティラノサウルス・トリケラトプス・プテラノドン。相手は残りの6種からランダムに3体。

## 遊び方
1. 下半分のパネルで、自分の3体それぞれの技を選ぶ（3タップ）。3体目を選ぶとターン開始。
2. 素早さが速い順（先制技は最初）に6体が動く。順番は真ん中の「行動順」に出る。
3. 自分の攻撃中は赤い輪、相手の攻撃中は青い輪が縮む。輪が白い的に重なった瞬間に、画面のどこかをタップ（PC はクリックかスペースキー）。
   - 攻撃：ぴったり 1.5倍／おしい 1.2倍／外れ 1.0倍
   - 防御：ぴったり 0.6倍／おしい 0.8倍／外れ 1.0倍
4. 相手を3体とも倒せば勝ち。

## 自分のパソコンで動かす
`index.html` をブラウザで開くだけで遊べる（インターネットにつながっていると丸い文字のフォントが使われる）。
キャッシュなしの確認用サーバー：`python tools/serve.py` → http://localhost:8765/

## ファイルの場所
| 場所 | 中身 |
| --- | --- |
| `WBS.md` | 作業の一覧と進み具合 |
| `index.html` / `style.css` | ゲームの入れ物と見た目 |
| `js/common/` | Tanuki Box の共通土台（片手操作・日英切替・セーブ・効果音とミュート）。DUST DASH と同じもの |
| `js/game/config.js` | **調整用の数字**（ダメージの式・タイミングの幅と倍率・相手AIのうまさ・演出の速さ） |
| `js/game/data.js` | **恐竜と技のデータ表**（ステータス・技の威力と効果・絵の色や形） |
| `js/game/battle.js` | バトルのルール（行動順・攻撃相手・ダメージ・技の効果・相手AI）。画面を使わない計算だけ |
| `js/game/battle-view.js` | バトル画面（場・行動順・技えらび・タイミングの輪・演出） |
| `js/game/art.js` | 恐竜の SVG イラスト（体型8種を色・模様・頭の形・大きさで描き分け） |
| `js/game/art-tyranno.js` | 描きこみ版のティラノサウルス（あご・頭・しっぽ・足・腕を部品に分けて、技で別々に動かせる） |
| `js/game/anims.js` | 技ごとの攻撃アニメーション（ためる→打ちこむ→当たる→戻る）と演出の部品（残像・スピード線・噛みつき跡・衝撃波・擬音・ヒットストップ） |
| `js/game/sfx.js` | 効果音 |
| `js/game/lang.js` | 画面の文字（日本語・英語） |
| `js/game/share.js` | X シェア（文章とゲームの URL） |
| `js/game/main.js` | 起動・画面の切りかえ・セーブ |
| `tools/sim.js` | バランス確認用シミュレーション（`node tools/sim.js`） |
| `tools/art-preview.html` | 全恐竜の絵を並べて確認するページ（`#tyranno` を付けると1体だけ大きく、描きこむ前と並べて表示） |
| `tools/serve.py` | キャッシュしない確認用サーバー |

## バランス確認
```
node tools/sim.js          # 大会の強さごとに 3000 戦（チームはランダム）
node tools/sim.js 10000    # 回数を変える
```
平均ターン数・勝率・ターン数の分布が出る。プレイヤーのタイミングは「ふつうの人」（攻撃：ぴったり35%・おしい40%）を想定。
